# 🧮 Calculadora Java Swing

Projeto de uma calculadora gráfica desenvolvida em **Java 21**, utilizando a biblioteca **Java Swing** para construção da interface gráfica.

Este projeto foi desenvolvido com o objetivo de praticar programação orientada a objetos, lógica de programação e desenvolvimento de aplicações desktop em Java.

## 🚀 Tecnologias utilizadas

- Java 21
- Java Swing
- IntelliJ IDEA
- Git e GitHub

## ⚙️ Funcionalidades

- Interface gráfica intuitiva.
- Visor para exibição dos números e resultados.
- Operações matemáticas básicas.
- Botões para interação com a calculadora.

## 💻 Como executar o projeto

**1. Clone o repositório:**

```bash
git clone https://github.com/Elirosal/CalculadoraJava.git
```

**2. Entre na pasta:**

```bash
cd CalculadoraJava
```

**3. Compile os arquivos Java:**

```bash
javac -d out src/*.java
```

**4. Execute a aplicação:**

```bash
java -cp out Main
```
